## ADDED Requirements

### Requirement: フィールド選択画面のフルスクリーン表示
システムは、フィールド選択画面を、ターミナルの alternate screen buffer を用いたフルスクリーン表示で提供しなければならない(SHALL)。この表示は既定の挙動とし、ウィンドウ内表示(画面の一部のみを占有する表示)に切り替えるオプションは提供しない。

#### Scenario: フィールド選択画面がフルスクリーンで表示される
- **WHEN** ユーザーが検索画面またはキャッシュされた直前アイテムからフィールド選択画面へ遷移する
- **THEN** システムはターミナルの全画面を占有する形でフィールド選択画面を表示する

#### Scenario: フィールド選択画面終了後に元の画面内容が復元される
- **WHEN** ユーザーがフィールド選択画面を終了する(明示的な終了操作・検索画面への遷移のいずれの場合も含む)
- **THEN** システムはフィールド選択画面を開始する直前のターミナル画面内容を復元する
