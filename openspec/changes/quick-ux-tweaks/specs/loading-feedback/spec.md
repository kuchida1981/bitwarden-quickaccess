## ADDED Requirements

### Requirement: bw CLI呼び出し中のローディングメッセージ表示
システムは、`bw` CLI を呼び出して応答を待つ間、処理内容が分かるメッセージを標準エラー出力へ表示しなければならない(SHALL)。メッセージには、アイテム名・フィールド値などの機密情報を含めてはならない(SHALL NOT)。

#### Scenario: session unlock中にメッセージを表示する
- **WHEN** システムがキャッシュされた session を持たず `bw unlock` を実行する
- **THEN** `bw unlock` の実行前に、ロック解除中であることを示すメッセージが標準エラー出力に表示される

#### Scenario: vault一覧取得中にメッセージを表示する
- **WHEN** システムが検索画面を表示する前に `bw list items` を実行する
- **THEN** `bw list items` の実行前に、vault を読み込み中であることを示すメッセージが標準エラー出力に表示される

#### Scenario: アイテム詳細取得中にメッセージを表示する
- **WHEN** システムがフィールド選択画面を表示する前に対象アイテムの詳細(`bw get item`)を取得する
- **THEN** 取得処理の実行前に、アイテム情報を取得中であることを示すメッセージが標準エラー出力に表示される

#### Scenario: フィールド値取得中にメッセージを表示する
- **WHEN** システムがユーザー名・パスワード・TOTP のいずれかの値を `bw get username/password/totp` で取得する
- **THEN** 取得処理の実行前に、値を取得中であることを示すメッセージが標準エラー出力に表示される
