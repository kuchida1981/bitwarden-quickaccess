## ADDED Requirements

### Requirement: アプリ表示名のローカライズ
システムは、ウィンドウタイトルおよびアンロック画面の見出しに表示するアプリ名を、判定された表示言語(日本語または英語)でローカライズしなければならない(SHALL)。これらの表示名は、配布・自動更新に用いる内部的なプロダクト名(`productName`)とは独立して扱われる。

#### Scenario: 日本語環境でのアプリ表示名
- **WHEN** 表示言語が日本語の状態でクイックアクセスを表示する
- **THEN** ウィンドウタイトルおよびアンロック画面の見出しに日本語の表示名が使われる

#### Scenario: 英語環境でのアプリ表示名
- **WHEN** 表示言語が英語の状態でクイックアクセスを表示する
- **THEN** ウィンドウタイトルおよびアンロック画面の見出しに英語の表示名が使われる
