## MODIFIED Requirements

### Requirement: トレイメニューでのアプリ名・バージョン表示
トレイメニューは、アプリケーション名とバージョン番号を表示しなければならない(SHALL)。バージョン番号は、ビルド時の実際のgit状態(タグ・コミット)から動的に導出されなければならない(SHALL)。`.git` またはgitコマンドが利用できない環境では、`Cargo.toml` の `version` の値にフォールバックしなければならない(SHALL)。

#### Scenario: トレイメニューを開くとアプリ名とバージョンが確認できる
- **WHEN** トレイメニューを開く
- **THEN** アプリケーション名とバージョン番号を含む項目が表示されている

#### Scenario: リリースタグちょうどのコミットでビルドした場合
- **WHEN** リリースタグ(例: `v1.1.0`)が指すコミットでビルドされたアプリを起動する
- **THEN** トレイメニューには `v1.1.0` のようにクリーンなバージョンが表示される

#### Scenario: タグより後のコミットでセルフビルドした場合
- **WHEN** 最新のリリースタグより後のコミットでセルフビルドしたアプリを起動する
- **THEN** トレイメニューには `v1.1.0-3-gabc1234` のような、正式リリースそのものではないことが分かる形式のバージョンが表示される
