## ADDED Requirements

### Requirement: 検索画面のフルスクリーン表示
システムは、検索画面(インクリメンタルサーチ画面)を、ターミナルの alternate screen buffer を用いたフルスクリーン表示で提供しなければならない(SHALL)。この表示は既定の挙動とし、ウィンドウ内表示(画面の一部のみを占有する表示)に切り替えるオプションは提供しない。

#### Scenario: 検索画面がフルスクリーンで表示される
- **WHEN** ユーザーが検索画面を開始する
- **THEN** システムはターミナルの全画面を占有する形で検索画面を表示する

#### Scenario: 検索画面終了後に元の画面内容が復元される
- **WHEN** ユーザーが検索画面を終了する(アイテム選択・Esc によるキャンセルのいずれの場合も含む)
- **THEN** システムは検索画面を開始する直前のターミナル画面内容を復元する
