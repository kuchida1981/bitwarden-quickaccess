## ADDED Requirements

### Requirement: fzfの最低バージョン確認
システムは、起動時に `fzf` のバージョンが本ツールの要求する最低バージョン以上であることを確認しなければならない(SHALL)。バージョンが不足している場合、またはバージョンを判定できない場合、システムはアップグレード方法を案内した上でエラー終了しなければならず(SHALL)、要求バージョン未満の状態での起動を許してはならない(SHALL NOT)。

#### Scenario: fzfが要求バージョン以上の場合は通常どおり起動する
- **WHEN** インストールされている `fzf` のバージョンが要求する最低バージョン以上である
- **THEN** システムはこのチェックを通過し、後続の preflight チェックへ進む

#### Scenario: fzfのバージョンが要求バージョン未満の場合はエラー終了する
- **WHEN** インストールされている `fzf` のバージョンが要求する最低バージョン未満である
- **THEN** システムは検出したバージョンと要求バージョン、アップグレード方法の案内を表示し、0以外の終了コードで終了する

#### Scenario: fzfのバージョンを判定できない場合はエラー終了する
- **WHEN** `fzf --version` の出力からバージョン文字列を取得できない
- **THEN** システムは要求バージョンとアップグレード方法の案内を表示し、0以外の終了コードで終了する
