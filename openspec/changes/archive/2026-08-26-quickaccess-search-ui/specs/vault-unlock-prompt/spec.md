## ADDED Requirements

### Requirement: ロック中のアンロックフォーム表示
ポップアップウィンドウは、vaultがロックされている状態で表示された場合、マスターパスワード入力フォームを表示しなければならない(SHALL)。

#### Scenario: ロック中にポップアップを開くとアンロックフォームが出る
- **WHEN** vaultがロックされている状態でポップアップウィンドウが表示される
- **THEN** マスターパスワード入力フォームが表示される

### Requirement: アンロック成功時の画面遷移
アンロックフォームの送信が成功した場合、ポップアップウィンドウは検索画面に切り替わらなければならない(SHALL)。

#### Scenario: 正しいパスワードでアンロックすると検索画面になる
- **WHEN** ユーザーが正しいマスターパスワードを入力してアンロックフォームを送信する
- **THEN** ポップアップウィンドウの表示が検索画面に切り替わる

### Requirement: アンロック失敗時のエラー表示
アンロックフォームの送信が失敗した場合、ポップアップウィンドウはエラーメッセージを表示し、再入力を可能にしなければならない(SHALL)。

#### Scenario: 誤ったパスワードでアンロックに失敗する
- **WHEN** ユーザーが誤ったマスターパスワードを入力してアンロックフォームを送信する
- **THEN** エラーメッセージが表示され、パスワード入力欄はクリアされ再入力できる状態になる
