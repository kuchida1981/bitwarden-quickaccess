## REMOVED Requirements

### Requirement: 行フォーカス時のショートカットヒント表示
**Reason**: ショートカットヒントは行ごとの埋め込み表示ではなく、ポップアップ下部の常時表示グローバル領域(`quickaccess-status-footer`)に一本化することになったため、行ごとの表示は不要になった。
**Migration**: ショートカットヒントの表示は `quickaccess-status-footer` の「グローバル領域でのショートカットヒント表示」要件を参照。

一覧の行がフォーカス(マウスホバーまたはキーボード操作)された場合、利用可能なショートカット(ユーザー名コピー/パスワードコピー/TOTPコピー/ブラウザで開く)のヒントが表示されなければならない(SHALL)。

#### Scenario: 行にフォーカスするとヒントが表示される
- **WHEN** 一覧のいずれかの行にフォーカスが当たる
- **THEN** その行に対応するショートカットヒント(`⌘C` ユーザー名コピー / `⌘⇧C` パスワードコピー / `⌥⌘C` TOTPコピー / `Enter` ブラウザで開く)が表示される
