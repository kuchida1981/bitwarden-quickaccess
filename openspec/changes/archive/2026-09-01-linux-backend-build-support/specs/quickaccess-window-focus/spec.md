## MODIFIED Requirements

### Requirement: ポップアップを閉じた後の直前アプリへのフォーカス復帰
システムは、macOS 環境において、ポップアップウィンドウを表示する直前にフォアグラウンドだった他のアプリケーションを記録し、ポップアップウィンドウが非表示になった際に、記録したアプリケーションを再度アクティブ化しなければならない(SHALL)。記録したアプリケーションが既に終了している等の理由で再アクティブ化できない場合、エラーとせず何もしない(SHALL NOT crash)。
非 macOS (Linux 等) 環境においては、最前面アプリの記録および復帰処理は no-op（安全なスキップ）として動作しなければならない(SHALL)。

#### Scenario: コピー操作後に元のアプリへフォーカスが戻る (macOS)
- **WHEN** macOS 上で他のアプリケーションを操作している状態からホットキーでポップアップを表示し、アイテムのフィールドをコピーしてポップアップが自動的に閉じる
- **THEN** ポップアップを表示する直前にフォアグラウンドだったアプリケーションが再びフォーカスされた状態になる

#### Scenario: ホットキーの再押下で閉じた場合もフォーカスが戻る (macOS)
- **WHEN** macOS 上で他のアプリケーションを操作している状態からホットキーでポップアップを表示し、何も操作せずに再度ホットキーを押してポップアップを閉じる
- **THEN** ポップアップを表示する直前にフォアグラウンドだったアプリケーションが再びフォーカスされた状態になる

#### Scenario: 記録したアプリが既に終了している (macOS)
- **WHEN** macOS 上でポップアップ表示中に、表示直前にフォアグラウンドだったアプリケーションが終了する
- **THEN** ポップアップが閉じる際にフォーカス復帰処理は何も行わず、アプリケーションはクラッシュしない

#### Scenario: 非 macOS 環境でのポップアップ開閉 (Linux 等)
- **WHEN** Linux 等の非 macOS 環境でポップアップを表示し、閉じる操作（コピーやホットキー再押下等）が行われる
- **THEN** 最前面アプリの記録およびフォーカス復帰処理はエラーを発生させることなくスキップされ、アプリケーションは正常に動作を継続する
