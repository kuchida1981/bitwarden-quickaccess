## ADDED Requirements

### Requirement: 必須外部コマンドの存在確認
システムは、起動時に必須の外部コマンド(`bw`、`jq`、`fzf`)が実行可能であることを確認しなければならない(SHALL)。いずれかが存在しない場合、システムは該当コマンドのインストール方法を案内した上でエラー終了しなければならず(SHALL)、代替手段への黙示的なフォールバックを行ってはならない(SHALL NOT)。

#### Scenario: 必須コマンドが揃っている場合は通常どおり起動する
- **WHEN** `bw`・`jq`・`fzf` がすべて実行可能な状態でツールを起動する
- **THEN** システムは preflight チェックを通過し、通常の検索画面(または直前アイテムのフィールド選択画面)に進む

#### Scenario: 必須コマンドが不足している場合はエラー終了する
- **WHEN** `bw`・`jq`・`fzf` のいずれかが実行可能でない状態でツールを起動する
- **THEN** システムは不足しているコマンド名とインストール方法の案内を表示し、0以外の終了コードで終了する

### Requirement: クリップボードコピーコマンドの検出と確認
システムは、実行環境(OS、および Linux の場合はディスプレイサーバー種別)に応じたクリップボードコピーコマンド(macOS: `pbcopy`、Wayland: `wl-copy`、X11: `xclip` または `xsel`)を判定し、対応するコマンドが実行可能であることを確認しなければならない(SHALL)。該当コマンドが存在しない場合、インストール方法を案内した上でエラー終了しなければならない(SHALL)。

#### Scenario: 環境に応じたクリップボードコマンドが利用可能な場合
- **WHEN** 実行中の OS/ディスプレイサーバーに対応するクリップボードコピーコマンドが実行可能である
- **THEN** システムは preflight チェックを通過する

#### Scenario: クリップボードコマンドが見つからない場合はエラー終了する
- **WHEN** 実行中の OS/ディスプレイサーバーに対応するクリップボードコピーコマンドが1つも見つからない
- **THEN** システムは想定されるコマンド名とインストール方法の案内を表示し、0以外の終了コードで終了する

### Requirement: keychain連携ツールの疎通確認
システムは、session token のキャッシュに使用する OS キーチェーン連携コマンド(macOS: `security`、Linux: `secret-tool`)について、起動時に疎通確認を行わなければならない(SHALL)。Linux で `secret-tool` は存在するがバックエンド(キーリングデーモン)への疎通に失敗する場合、システムはキャッシュを利用せず毎回 `bw unlock` を要求する動作にフォールバックし、その旨をユーザーに明示しなければならない(SHALL)。

#### Scenario: keychain連携が正常に利用できる場合
- **WHEN** keychain 連携コマンドが実行可能かつバックエンドへの疎通に成功する
- **THEN** システムは session token のキャッシュ機能を有効にする

#### Scenario: Linuxでキーリングデーモンに疎通できない場合
- **WHEN** `secret-tool` は実行可能だが、キーリングデーモンへの疎通(store/lookup)が失敗する
- **THEN** システムはキャッシュを使用しない旨をユーザーに表示した上で、毎回 `bw unlock` を要求する動作を続行する
