## MODIFIED Requirements

### Requirement: ユーザー名コピー
一覧の行にフォーカスがある状態で、macOS では `⌘C`、Linux 等の非 macOS 環境では `Ctrl+C` が押下された場合、そのアイテムのユーザー名がクリップボードにコピーされなければならない(SHALL)。

#### Scenario: フォーカス行のユーザー名をコピーする (macOS)
- **WHEN** macOS 上で一覧のある行にフォーカスがある状態で `⌘C` が押下される
- **THEN** そのアイテムのユーザー名がクリップボードにコピーされる

#### Scenario: フォーカス行のユーザー名をコピーする (Linux)
- **WHEN** Linux 上で一覧のある行にフォーカスがある状態で `Ctrl+C` が押下される
- **THEN** そのアイテムのユーザー名がクリップボードにコピーされる

### Requirement: パスワードコピー
一覧の行にフォーカスがある状態で、macOS では `⌘⇧C`、Linux 等の非 macOS 環境では `Ctrl+Shift+C` が押下された場合、そのアイテムのパスワードがクリップボードにコピーされなければならない(SHALL)。

#### Scenario: フォーカス行のパスワードをコピーする (macOS)
- **WHEN** macOS 上で一覧のある行にフォーカスがある状態で `⌘⇧C` が押下される
- **THEN** そのアイテムのパスワードがクリップボードにコピーされる

#### Scenario: フォーカス行のパスワードをコピーする (Linux)
- **WHEN** Linux 上で一覧のある行にフォーカスがある状態で `Ctrl+Shift+C` が押下される
- **THEN** そのアイテムのパスワードがクリップボードにコピーされる

### Requirement: TOTPコピー
一覧の行にフォーカスがある状態で、macOS では `⌥⌘C`、Linux 等の非 macOS 環境では `Alt+Ctrl+C` が押下された場合、そのアイテムの現在時刻のTOTPコードがクリップボードにコピーされなければならない(SHALL)。

#### Scenario: フォーカス行のTOTPコードをコピーする (macOS)
- **WHEN** macOS 上でTOTPが設定されたアイテムの行にフォーカスがある状態で `⌥⌘C` が押下される
- **THEN** 現在時刻に対応するTOTPコードがクリップボードにコピーされる

#### Scenario: フォーカス行のTOTPコードをコピーする (Linux)
- **WHEN** Linux 上でTOTPが設定されたアイテムの行にフォーカスがある状態で `Alt+Ctrl+C` が押下される
- **THEN** 現在時刻に対応するTOTPコードがクリップボードにコピーされる

### Requirement: 検索ボックスフォーカス時のショートカット非干渉
検索ボックスにフォーカスがある間は、macOS の `⌘C` および Linux の `Ctrl+C` は、テキスト選択がある場合はOS標準のテキストコピー動作として扱われ、独自のユーザー名コピーアクションを発火してはならない(SHALL NOT)。

#### Scenario: 検索ボックスにフォーカスがありテキスト選択がある間のコピー (macOS)
- **WHEN** macOS 上で検索ボックスにテキスト選択がある状態で `⌘C` が押下される
- **THEN** ユーザー名コピーアクションは発火せず、通常のテキストコピー動作のみが行われる

#### Scenario: 検索ボックスにフォーカスがありテキスト選択がある間のコピー (Linux)
- **WHEN** Linux 上で検索ボックスにテキスト選択がある状態で `Ctrl+C` が押下される
- **THEN** ユーザー名コピーアクションは発火せず、通常のテキストコピー動作のみが行われる
