## Purpose

アプリのウィンドウ配色を、macOS のシステム外観設定(ライト/ダーク)に自動追従させ、ネイティブアプリと並べたときに違和感のない見た目を提供する。

## ADDED Requirements

### Requirement: システム外観設定への追従
アプリのウィンドウは、macOS のシステム外観設定がダークモードのとき、ダークモード用の配色で表示されなければならない(SHALL)。システム外観設定がライトモードのときは、既存のライトモード配色で表示されなければならない(SHALL)。

#### Scenario: システムがダークモードのとき
- **WHEN** macOS のシステム外観設定がダークモードに設定された状態でアプリのウィンドウ(アンロック画面・検索画面・エラー画面・ヘルプオーバーレイを含む)が表示される
- **THEN** 背景・テキスト・ボーダー・アクセントカラーがダークモード用の配色で表示される

#### Scenario: システムがライトモードのとき
- **WHEN** macOS のシステム外観設定がライトモードに設定された状態でアプリのウィンドウが表示される
- **THEN** 背景・テキスト・ボーダー・アクセントカラーが従来のライトモード配色で表示される

#### Scenario: 表示中にシステム外観設定が切り替わったとき
- **WHEN** アプリのウィンドウが表示されている状態で、macOS のシステム外観設定がライト/ダークの間で切り替わる
- **THEN** アプリを再起動することなく、ウィンドウの配色が新しい外観設定に追従して切り替わる

### Requirement: 両モードでの視認性維持
すべての画面(アンロック画面・検索画面・エラー画面・ヘルプオーバーレイ)は、ライトモード・ダークモードのいずれにおいても、テキストと背景・アクセント色とアクセント上の文字が判読可能なコントラストを保たなければならない(SHALL)。エラーメッセージ(アンロック失敗時のエラー、バックエンド接続エラー画面)は、いずれのモードでも通常テキストと区別できる強調色で表示されなければならない(SHALL)。

#### Scenario: ダークモードでのエラー表示
- **WHEN** ダークモードで、マスターパスワードの入力誤りによりアンロックエラーが表示される、またはバックエンド接続エラー画面が表示される
- **THEN** エラーテキストがダークモード背景に対して十分なコントラストを持つ強調色で表示される

#### Scenario: ダークモードでのフォーカス項目表示
- **WHEN** ダークモードで検索結果一覧のアイテムにフォーカスが当たる、またはアクションメニューの項目にフォーカスが当たる
- **THEN** フォーカスされた項目の背景色と文字色が、ライトモードと同様に判読可能なコントラストを保って表示される

#### Scenario: ダークモードでの入力欄表示
- **WHEN** ダークモードでマスターパスワード入力欄または検索ボックスが表示される
- **THEN** 入力欄の背景色がページ背景より明確に区別できるダーク配色で表示され、入力文字・プレースホルダーが判読可能なコントラストを保って表示される
