## MODIFIED Requirements

### Requirement: bw serve CLI 前提チェック
本サービスは、`bw serve` 起動前に `bw` CLI が存在し、`serve` サブコマンドをサポートするバージョンであることを確認し、満たさない場合は起動を中止してエラー状態を返さなければならない(SHALL)。

`bw` 実行ファイルの所在は、以下の順序で最初に見つかったものを採用しなければならない(SHALL)。

1. 設定ファイル(`$XDG_CONFIG_HOME/bw-quickaccess/bw_path.txt`。`XDG_CONFIG_HOME` が未設定の場合は `~/.config/bw-quickaccess/bw_path.txt`)に書かれた絶対パス。ファイルが存在し、かつ記載されたパスが実在する実行可能ファイルを指す場合に限り採用する。
2. 既知のインストール先を先頭から順に確認する: `/opt/homebrew/bin/bw` → `/usr/local/bin/bw`。
3. 上記いずれでも見つからない場合、`"bw"` をそのまま実行コマンドとして用いる(現在のプロセスが継承しているPATH上での解決に委ねる、最終フォールバック)。

いずれの方法でも実行可能な `bw` に到達できなかった場合(3のフォールバックも失敗した場合)は、`bw serve` を起動せず、CLI未検出のエラー状態を返さなければならない(SHALL)。このエラー状態には、設定ファイルにパスを明示指定する方法の案内を含めなければならない(SHALL)。

#### Scenario: 設定ファイルで指定したパスのbwが使われる
- **WHEN** 設定ファイルに実在する実行可能な `bw` の絶対パスが書かれている
- **THEN** 既知のインストール先やPATHに関わらず、設定ファイルに書かれたパスの `bw` が使用される

#### Scenario: 設定ファイルが無い場合は既知のインストール先が使われる
- **WHEN** 設定ファイルが存在しない、または記載されたパスが実行可能ファイルとして存在しない
- **AND** 既知のインストール先(`/opt/homebrew/bin/bw` または `/usr/local/bin/bw`)に実行可能な `bw` が存在する
- **THEN** 既知のインストール先のうち先に見つかったものの `bw` が使用される

#### Scenario: 設定ファイルにも既知のインストール先にも無い場合はPATHにフォールバックする
- **WHEN** 設定ファイルが存在せず、既知のインストール先にも実行可能な `bw` が存在しない
- **THEN** 現在のプロセスが継承しているPATHの解決に委ねて `"bw"` を実行しようとする

#### Scenario: bw CLIが見つからない
- **WHEN** 設定ファイル・既知のインストール先・PATHのいずれによっても実行可能な `bw` に到達できない
- **THEN** `bw serve` を起動せず、CLI未検出のエラー状態を返す
- **THEN** エラー状態には、設定ファイルにパスを明示指定する方法の案内が含まれる
