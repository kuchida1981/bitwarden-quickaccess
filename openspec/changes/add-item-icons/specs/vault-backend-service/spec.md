## ADDED Requirements

### Requirement: アイテムのアイコン情報取得
本サービスは、アイテム検索・アイテム取得インターフェースの戻り値に、アイテムごとのアイコン取得に用いるドメイン情報(`login.uris[0].uri` から抽出したホスト名)を含めなければならない(SHALL)。情報が得られない(URIを持たない等)アイテムについては、アイコン関連情報を含めなくてよい(MAY)。

#### Scenario: URIを持つアイテムにアイコン関連情報が含まれる
- **WHEN** `login.uris` にURIを持つアイテムを検索・取得する
- **THEN** 戻り値にそのアイテムのアイコン取得に用いるドメイン情報が含まれる

#### Scenario: URIを持たないアイテムにはアイコン関連情報が含まれない
- **WHEN** `login` を持たない、または `login.uris` が空のアイテムを検索・取得する
- **THEN** 戻り値にそのアイテムのアイコン関連情報は含まれない
