# backend-connection-error-display

## Purpose

`bw`(Bitwarden CLI)の前提条件(コマンドの存在、`bw serve`対応バージョン、`bw login`済みであること)が満たされずバックエンド接続が確立できない場合に、原因を示す専用のエラー画面を検索ポップアップに表示する。ユーザーがマスターパスワードを入力しても意味のない誤解を招く画面(アンロックフォーム)を表示し続けることを防ぐ。

## Requirements

### Requirement: 接続エラー画面の表示
バックエンド接続状態が `disconnected`(`bw` CLI未検出、`bw serve`が対応していないバージョン、`bw login` 未実施のいずれか)である状態で検索ポップアップが表示された場合、システムはマスターパスワード入力フォームではなく、原因を示す専用のエラー画面を表示しなければならない(SHALL)。

#### Scenario: bw CLI未検出時にエラー画面が表示される
- **WHEN** `bw` コマンドが見つからない状態でクイックアクセスを開く
- **THEN** マスターパスワード入力フォームではなく、`bw` コマンドが見つからない旨を示すエラー画面が表示される

#### Scenario: bw serve未対応バージョン時にエラー画面が表示される
- **WHEN** `bw serve` に対応していないバージョンの `bw` がインストールされた状態でクイックアクセスを開く
- **THEN** マスターパスワード入力フォームではなく、`bw serve` に対応していない旨を示すエラー画面が表示される

#### Scenario: bw未ログイン時にエラー画面が表示される
- **WHEN** `bw login` を実施していない状態でクイックアクセスを開く
- **THEN** マスターパスワード入力フォームではなく、ログインが必要である旨を示すエラー画面が表示される

### Requirement: 起動直後の一時的なdisconnectedはエラー画面にしない
バックエンド接続状態が `disconnected` であっても、具体的なエラーメッセージがまだ記録されていない場合(preflightチェックや`bw serve`起動確認が完了していない、起動直後の一時的な状態)、システムはエラー画面ではなくアンロック画面を表示しなければならない(SHALL)。エラー画面は、実際にエラーメッセージが記録されている場合にのみ表示されなければならない(SHALL)。

#### Scenario: 起動直後の一時的なdisconnectedではアンロック画面が表示される
- **WHEN** アプリ起動直後、バックエンドとの接続確認がまだ完了していない(エラーメッセージが記録されていない)状態でクイックアクセスを開く
- **THEN** エラー画面ではなくアンロック画面が表示される

### Requirement: 正常系画面への影響なし
接続状態が `locked` または `unlocked` である場合、システムは従来通りそれぞれアンロック画面・検索画面を表示しなければならない(SHALL)。

#### Scenario: ロック中は従来通りアンロック画面が表示される
- **WHEN** バックエンド接続状態が `locked` の状態でクイックアクセスを開く
- **THEN** マスターパスワード入力フォームが表示される

#### Scenario: アンロック済みは従来通り検索画面が表示される
- **WHEN** バックエンド接続状態が `unlocked` の状態でクイックアクセスを開く
- **THEN** 検索画面が表示される
