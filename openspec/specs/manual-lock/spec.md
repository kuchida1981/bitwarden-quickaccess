# manual-lock

## Purpose

ユーザー操作(検索画面のショートカット macOS: `⌘L` / Linux: `Ctrl+L`、トレイメニューの「今すぐロック」)による明示的なVaultロック機能を提供する。`idle-auto-lock` によるアイドルタイムアウト待ちに頼らず、離席時などに任意のタイミングで即座にロックできるようにする。

## Requirements

### Requirement: 検索画面からの明示的ロック
検索画面(アンロック済み状態)で、macOS では `⌘L`、Linux 等の非 macOS 環境では `Ctrl+L` が押下された場合、システムはVaultを直ちにロックし、ポップアップの表示をアンロック画面に切り替えなければならない(SHALL)。

#### Scenario: 検索画面からショートカットでロックしアンロック画面に切り替わる (macOS)
- **WHEN** macOS 上で検索画面が表示されている状態で `⌘L` が押下される
- **THEN** Vaultがロックされ、ポップアップの表示がマスターパスワード入力フォームに切り替わる

#### Scenario: 検索画面からショートカットでロックしアンロック画面に切り替わる (Linux)
- **WHEN** Linux 上で検索画面が表示されている状態で `Ctrl+L` が押下される
- **THEN** Vaultがロックされ、ポップアップの表示がマスターパスワード入力フォームに切り替わる

### Requirement: トレイメニューからの明示的ロック
トレイメニューの「今すぐロック」項目が選択された場合、システムはVaultを直ちにロックしなければならない(SHALL)。この項目は、Vaultがアンロック済みの場合のみ有効でなければならない(SHALL)。

#### Scenario: トレイメニューからロックできる
- **WHEN** Vaultがアンロック済みの状態でトレイメニューの「今すぐロック」項目が選択される
- **THEN** Vaultがロックされる

#### Scenario: ロック中・未接続時は項目が無効
- **WHEN** Vaultがロック済み、または未接続の状態でトレイメニューを開く
- **THEN** 「今すぐロック」項目は無効化されており選択できない

### Requirement: ポップアップ表示中の状態変化への追従
検索画面が表示されたままの状態で、トレイメニュー等ポップアップの外からVaultがロックされた場合、システムはポップアップを非表示にすることなく、表示中のままアンロック画面に切り替えなければならない(SHALL)。

#### Scenario: 検索画面を開いたままトレイからロックすると即座にアンロック画面へ切り替わる
- **WHEN** 検索画面が表示されたままの状態でトレイメニューの「今すぐロック」項目が選択される
- **THEN** ポップアップを閉じたり再度開いたりすることなく、表示中の画面が直ちにマスターパスワード入力フォームへ切り替わる

### Requirement: 手動ロック時のクリップボードクリア
検索画面のショートカット(macOS: `⌘L` / Linux: `Ctrl+L`)またはトレイメニューの「今すぐロック」によってVaultが手動でロックされた場合、その時点でクリップボードの中身が直前に `copy_field` で書き込まれた値のままであれば、システムは即座にクリップボードをクリアしなければならない(SHALL)。クリップボードの中身が既に別の値に変わっている場合、システムはそれを上書き・消去してはならない(SHALL NOT)。

#### Scenario: コピー直後に手動ロックするとクリップボードがクリアされる
- **WHEN** パスワードをコピーした直後(クリップボードの中身がそのパスワードのまま)に手動ロックショートカットでVaultをロックする
- **THEN** ロックと同時にクリップボードの中身が空になる

#### Scenario: 別の値をコピー済みの場合は手動ロックしてもクリアされない
- **WHEN** パスワードをコピーした後、ユーザーが別の値をクリップボードにコピーしてから手動ロックショートカットでVaultをロックする
- **THEN** クリップボードの中身は変更されず、コピーされた別の値がそのまま残る
