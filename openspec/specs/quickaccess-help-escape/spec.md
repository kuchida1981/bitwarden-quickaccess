# quickaccess-help-escape

## Purpose

検索ポップアップ表示中に `Esc` キーでポップアップを閉じる手段と、ショートカット(macOS: `⌘/` / Linux: `Ctrl+/`)で本アプリのショートカット一覧をその場にオーバーレイ表示する手段を提供する。1Password Quick Accessと同等の使用感に近づけるとともに、README等のドキュメントを確認しなくてもアプリ内でキー操作を確認できるようにする。`Esc` の挙動は表示中のUIの階層(ヘルプ表示中 > アクションメニュー表示中 > 通常)に従う。

## Requirements

### Requirement: Escapeキーによるポップアップのクローズ
検索ポップアップが表示されている状態で、ヘルプオーバーレイもアクションメニューも表示されていないときに `Esc` キーが押下された場合、システムはポップアップを非表示にしなければならない(SHALL)。

#### Scenario: 通常状態でEscapeを押すとポップアップが閉じる
- **WHEN** 検索ポップアップが表示され、ヘルプもアクションメニューも表示されていない状態で `Esc` キーが押下される
- **THEN** ポップアップが非表示になる

### Requirement: ショートカットヘルプの表示
検索ポップアップが表示されている状態で、macOS では `⌘/`、Linux 等の非 macOS 環境では `Ctrl+/` が押下された場合、システムは本アプリで利用可能なショートカットの一覧をその場にオーバーレイ表示しなければならない(SHALL)。

#### Scenario: ショートカットでヘルプが表示される (macOS)
- **WHEN** macOS 上で検索ポップアップが表示されている状態で `⌘/` が押下される
- **THEN** ショートカット一覧のオーバーレイが表示される

#### Scenario: ショートカットでヘルプが表示される (Linux)
- **WHEN** Linux 上で検索ポップアップが表示されている状態で `Ctrl+/` が押下される
- **THEN** ショートカット一覧のオーバーレイが表示される

#### Scenario: ヘルプ表示中にアクションメニューが開いていた場合は閉じる
- **WHEN** アクションメニューが展開されている状態でヘルプ表示ショートカットが押下される
- **THEN** アクションメニューが閉じ、ショートカット一覧のオーバーレイが表示される

### Requirement: ヘルプオーバーレイのクローズ
ヘルプオーバーレイが表示されている間にヘルプ表示ショートカット(macOS: `⌘/` / Linux: `Ctrl+/`)または `Esc` が押下された場合、システムはヘルプオーバーレイを閉じて通常の検索画面に戻さなければならない(SHALL)。ヘルプオーバーレイが表示されている間、それ以外のキー入力(検索文字入力、アイテム間移動等)を処理してはならない(SHALL NOT)。

#### Scenario: ヘルプ表示中にヘルプショートカットを押すと閉じる
- **WHEN** ヘルプオーバーレイが表示されている状態でヘルプ表示ショートカットが押下される
- **THEN** ヘルプオーバーレイが閉じ、通常の検索画面に戻る

#### Scenario: ヘルプ表示中にEscapeを押すと閉じる(ポップアップ自体は閉じない)
- **WHEN** ヘルプオーバーレイが表示されている状態で `Esc` キーが押下される
- **THEN** ヘルプオーバーレイが閉じて通常の検索画面に戻り、ポップアップ自体は表示されたままになる

#### Scenario: ヘルプ表示中は検索文字入力が無視される
- **WHEN** ヘルプオーバーレイが表示されている状態で文字キーが押下される
- **THEN** 検索ボックスの内容は変化しない
