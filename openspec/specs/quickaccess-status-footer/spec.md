# quickaccess-status-footer

## Purpose

ポップアップウィンドウ(`global-hotkey-popup`)の検索画面下部に、フォーカス中の行によらず常時表示される共通のグローバル領域(フッタ)を提供する。フッタは、左側にログイン中アカウントを識別できる表示(頭文字アバター、hoverで完全なメールアドレスを表示)、右側に利用可能なショートカット(ユーザー名コピー/パスワードコピー/TOTPコピー/ブラウザで開く)のヒントを表示する。従来 `incremental-item-search` が行フォーカス時に行内へ埋め込んでいたショートカットヒント表示を統合し、`vault-backend-service` が提供するログイン中アカウントのメールアドレスを画面に反映する。

## Requirements

### Requirement: グローバル領域でのショートカットヒント表示
検索画面は、フォーカス中の行によらず、ポップアップ下部の常時表示領域(フッタ)にショートカットヒント(ユーザー名コピー/パスワードコピー/TOTPコピー/ブラウザで開く)を表示しなければならない(SHALL)。

#### Scenario: 検索画面を開くとフッタにヒントが表示される
- **WHEN** アンロック済みの状態でポップアップウィンドウが表示される
- **THEN** フッタにショートカットヒントが表示される

#### Scenario: 行フォーカスを移動してもフッタのヒントは変わらない
- **WHEN** ユーザーが矢印キーで行フォーカスを別の行に移動する
- **THEN** フッタのショートカットヒント表示は変化しない

### Requirement: ログイン中アカウントの表示
検索画面は、フッタにログイン中アカウントを識別できる表示(頭文字アバター)を表示しなければならない(SHALL)。ユーザーがその表示を確認した際、完全なメールアドレスを確認できなければならない(SHALL)。

#### Scenario: ログイン中アカウントのアバターが表示される
- **WHEN** アンロック済みの状態でポップアップウィンドウが表示される
- **THEN** フッタにログイン中アカウントのメールアドレスの先頭1文字を表示するアバターが表示される

#### Scenario: アバターにカーソルを合わせると完全なメールアドレスが確認できる
- **WHEN** ユーザーがフッタのアカウントアバターにマウスカーソルを合わせる
- **THEN** ログイン中アカウントの完全なメールアドレスが表示される

#### Scenario: アカウント情報が取得できない場合はアバターを表示しない
- **WHEN** ログイン中アカウントのメールアドレスが取得できない
- **THEN** フッタにアカウントアバターは表示されない
